# iPod Feel Simulator 3D

An authentic, tactile 3D simulator for the classic portable music player experience built with Three.js and the Web Audio API.

## Features
- **3D Interactive Stage:** Front-facing locked view matching classic styling on a solid black background.
- **Physical Headphone Jack:** Interactive 3.5mm plug animation that connects directly into the top headphone jack with mechanical sound effects and tactile feedback.
- **Interactive Click Wheel:** Rotary touch and drag controls with mechanical clicks, responsive center Select button, Menu navigation, Play/Pause, and skip controls.
- **Audio File Importer:** Drag and drop your own local audio files (.mp3, .wav, .m4a) to load and play them directly inside the simulator.
- **Authentic LCD Screen:** Simulated retro user interface with menus, track lists, progress bars, volume indicators, and backlight toggle.
- **Synthesized Sound Effects:** Web Audio API synthesized piezo clicks, button presses, hard-drive spin-up, and 3.5mm headphone jack snap effects.

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
