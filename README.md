# Feel Classic MP3 Experience

An interactive 3D web application featuring an iconic classic portable music player and wired earphones.

## Features
- **3D Interactive Stage:** Full 360-degree rotation and inspection using WebGL and Three.js.
- **Physical Headphone Jack:** Interactive 3.5mm plug animation that connects to the headphone port with tactile sound and pause-on-disconnect logic.
- **Audio File Importer:** Drag and drop your own local audio files (.mp3, .wav, .m4a) to load and play them directly on the virtual device.
- **Interactive LCD Screen:** Simulated retro user interface with menus, track lists, progress bars, volume indicators, and backlight toggle.
- **Color Customizer:** Circular color wheel and curated style presets to customize the device housing, wheel, and earphones in real time.
- **Tactile Sound Effects:** Synthesized click-wheel sounds and haptic vibration feedback for mobile devices.

## Getting Started
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
