Privacy Policy

100% Client-Side & Private: This application runs entirely inside your web browser. Any MP3 files or wallpaper images you import are processed locally via the Web Audio API and HTML5 File APIs. No audio files, telemetry, tracking cookies, or personal data are ever uploaded, recorded, or sent to any remote server.

Terms of Use

FeelPod 3D is an interactive 3D web simulator built to preserve and recreate the tactile joy of classic portable MP3 players. It is free and open-source software for personal non-commercial appreciation.
